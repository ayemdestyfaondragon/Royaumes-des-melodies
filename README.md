# Royaumes des Mélodies — Blind-Test Disney

Application web statique de blind-test Disney avec multijoueur à distance entre PC, téléphone et amis.

- **Multi à distance (PC + Téléphone)** : crée une room avec un code à 6 caractères ou partage le lien `?room=CODE` pour synchroniser les joueurs, le chat, les buzzers, les scores et les manches.
- **Onglet Réponse (Titre & Disney)** : saisie du titre (FR/EN) et du film/série Disney avec attribution automatique des points et historique des propositions de la manche.
- **Mode Local / Même écran** : gestion directe des scores (+1 Titre, +1 Disney, +2 Les deux, -1).
