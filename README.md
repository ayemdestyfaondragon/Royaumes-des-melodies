# Royaumes des Mélodies — Blind-Test Disney

Application web statique de blind-test Disney sans installation ni création de compte.

- **Mode Local / Même écran** : gestion des scores en direct (+1 Titre, +1 Disney, +2 Les deux, -1).
- **Mode Multi à distance (Salon)** : création de room avec code, pseudo, statut Prêt, chat de salon, buzzer horodaté et lien d'invitation (`?room=CODE`).
- **Onglet Réponse (Titre & Disney)** : vérification automatique du titre (FR/EN) et du film/série Disney, attribution des points et historique des propositions de la manche.
